    Giving coding agents an MCP server without writing to their settings

    Yardlet hands Codex, Claude Code and ACP agents its MCP server one session at a time: a launch argument for one, a request field for the others. Nothing is written to their settings.

    A Logger symbol missing on macOS 15 kept my Mac app from launching

    For four days Yardlet quit at launch on macOS 15. The SDK marks Logger.isEnabled(type:) as available since macOS 11, but macOS 15.6.1's libswiftos doesn't have it.
