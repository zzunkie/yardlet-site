Yardlet Changelog

What changed in each version of the Yardlet app. Yardlet updates itself, and GitHub Releases has the downloads. Changes on main that are not released yet are not listed.

Yardlet 0.11.9

November 6, 2026 · Release on GitHub

Intel Macs

  • Yardlet now has a version for Intel Macs with macOS 15 or later: Yardlet-0.11.9-x86_64.dmg, or brew install --cask zzunkie/tap/yardlet, which picks it on an Intel Mac. It updates itself from a feed of its own.
  • This is the first Intel version. It has been tried on one Intel Mac, a 2018 Mac mini with Intel UHD Graphics 630 on macOS 15.8, where it starts, streams a task and draws the built-in browser. Other Intel graphics (Iris, AMD Radeon) and macOS 26 on Intel have not been tried yet.
  • Its built-in browser plays no H.264 video or AAC audio, such as many sites' MP4 videos; WebM video (VP9, AV1) plays.
  • If you use it, please tell us how it goes, especially if the built-in browser closes or stays blank: a bug report with "Intel" chosen, or a note in Discussions.

Accounts and limits

  • New tasks start on Automatic when a harness has more than one account in automatic assignment, and the composer names the account it picks and why. An account you choose stays until you choose Automatic again.
  • A Claude Code task stopped by a usage limit that resets within a day continues by itself at the reset, as Claude Code does, and messages other tasks send it meanwhile wait until then. Settings › Harness Accounts › Continue automatically at usage limit turns this off.
  • Claude Code tasks move to an account with room when it costs nothing: an idle task on a nearly spent account moves once its prompt cache has expired, and a task a limit stopped continues on an account with room. Settings › Harness Accounts › Move tasks to an account with room turns this off.
  • Settings › Usage shows the tokens Claude Code and Codex record on this Mac, with their API-equivalent cost, beside the plan limits, and Home shows today's tokens and the limits closest to running out. The counts stay on this Mac; Settings › Usage › Count token usage turns this off and deletes them.
  • A limit card read back after a relaunch offers Resume again.
  • Each row in Settings › Harness Accounts has a "…" menu, with Sign Out… and Sign In With Another Account… for the default login.

Tasks

  • Group the task list by state (Needs input, Working, Unread, Idle) from the menu beside its search field.
  • Archived tasks open read-only without being unarchived.
  • Rename from Recent Conversation, beside Rename, has Claude Code or Codex name a long task again from its latest turns.
  • Move to Chats takes any task out of its project.
  • Codex tasks offer the Codex app's permissions: Ask for approval, Approve for me and Full access, and Custom when config.toml sets its own. You can choose one on the new-task screen, and schedules start with theirs.
  • Ask an agent in the conversation to change a Yardlet setting. A change that lowers a protection asks you on the approval card first.
  • Settings groups its sections under Personal, Integrations and Harnesses, and Accounts is now Harness Accounts.

Terminal

  • Settings › General › Terminal location opens the terminal below the conversation or as a tab in the side panel, as in the Codex app. Split Terminal in its header shows two shells side by side.
  • Shell code blocks in answers offer Run in terminal beside Copy code, and Run in terminal on a command card now runs the command instead of only typing it.

Browser, files and mail

  • Tasks share the built-in browser's sign-ins, so a site you sign in to is signed in for every task. A task gets a browser profile of its own only when its agent signs in to a site itself. Task profiles from earlier versions are merged once, and the emptied ones go to the Trash.
  • Agents try the password manager before handing a sign-in to you, and ask you before keeping a two-factor setup they started.
  • The blocked pop-up menu can always allow pop-ups from a site, so its sign-in or payment window opens as the site meant.
  • An agent can dismiss a site's permission request in its own task's tabs; only you can allow one.
  • Files previews movies, audio and animated images.
  • Agents can attach files to Outlook and IMAP drafts, as to Gmail drafts.
  • IMAP accounts on servers such as Naver Mail now get new-mail notices and search results.

Privacy

  • Screenshots an agent takes in the built-in browser hide keys and tokens, as its text results already did.
  • Links you open from mail open in the mailbox's own browser panel, out of reach of task agents.

Faster

  • Long conversations stream with much less work on the main thread, so the task list scrolls smoothly while a Codex answer streams, and scrolling up draws earlier turns one at a time.
  • Resizing a window with a long conversation, opening Personal agents and saving connector settings no longer hold up the app.
  • The Mac connects to the phone relay faster on many networks.

Fixes

  • Agents start with your login shell's PATH, so tools such as Homebrew's gh are found when Yardlet was opened from the Dock or Finder.
  • The Settings card in the session rail stays inside the side panel with a long model name.
  • Clicking a link in an answer that is still streaming no longer freezes Yardlet.
  • After a crash, Yardlet ends the Claude Code processes it left running instead of reporting their tasks as open in another app.
  • An ACP agent whose process ended on its own starts again for the next prompt.
  • A Codex turn cut off by a lost connection continues once the network is back.
  • A subagent asked to run on a model its harness does not offer stops with an error instead of using the default model.
  • Dragging a task row in the sidebar now works, to nest it under another task or drop it onto a split view.
  • A link followed directly by Korean, Japanese or Chinese text no longer takes in the text.
  • A chat without a title from its harness no longer shows its folder name.

Thanks

Thanks to @minsujang0 for reporting the slow scrolling while Codex streams (#183), the Settings card overflow (#483) and the missing PATH (#485), and for suggesting grouping tasks by state (#489).

Yardlet 0.11.8

November 2, 2026 · Release on GitHub

Mail

  • A mailbox shows the inboxes of your connected Gmail, Outlook Mail and IMAP accounts beside tasks and personal agents. It is off by default: turn it on in Settings › General › Mailbox, and Mail appears next to Tasks and Personal agents.
  • Read threads in place, write, reply and forward. What you write is saved to the account's own Drafts, and Send waits five seconds, during which Undo takes the message back.
  • Mail stays on the service. The mailbox reads it when it is shown and keeps it in memory only.
  • Images and other remote content in a message load only after Show images, so a sender cannot tell it was read.
  • Ask an agent hands a thread to a new chat by name. Agents read mail and write drafts through the account's connector, and every send goes through the agent's approval, where Claude Code's card has no Always allow.
  • Settings › Notifications › New mail tells you when mail reaches an inbox: Gmail's Primary tab, Outlook's Focused inbox.
  • Outlook accounts need a Microsoft app of your own for now, as in 0.11.7: Your own Microsoft app.
  • IMAP accounts (beta): mail services without an API connect over IMAP and SMTP in Settings › Connectors › Add connector › Mail (IMAP). The address picks the servers for Naver, Daum, Kakao, NAVER WORKS, iCloud, Yahoo, AOL, Zoho, Fastmail and Proton Mail Bridge, with the steps the service asks for first, or you enter another server by hand. The account uses an app password, kept in the keychain only. IMAP accounts have been tested against test servers so far; if one doesn't work with your service, please open an issue.

New

  • Side chats are temporary, as in the Codex app: a side chat stays out of the task list and ends when its tab closes or Yardlet quits. Fork task still keeps a conversation as a task, and side chats made before this update stay tasks.
  • A Claude Code side chat opens while its task is running.
  • Agents can read the task's terminal, read only, with keys and tokens hidden. Select output in the terminal and press ⌘⇧L, or right-click, to attach it to your message. Settings › General › Share the terminal with agents turns this off.
  • Choose account on a working task takes effect when its turn ends, and what you send meanwhile goes to the new account.
  • Scheduled tasks lists the ones that run next first, and folds paused schedules and finished one-offs below.
  • The phone nests tasks as the Mac's sidebar does.

Fixes

  • A Claude Code task reopened after a relaunch no longer opens with its latest message far above the composer.
  • An ACP agent, such as Antigravity, starts again after its last session closed instead of failing until Yardlet restarts.

Yardlet 0.11.7

November 2, 2026 · Release on GitHub

Security

  • Keys and tokens that a web page shows, such as an API key on a service's settings page, are hidden from what the browser tools return to agents. Settings › General › Hide keys and tokens turns this off.
  • Reading files from a paired phone is more limited.

Google

  • Yardlet's own Google app now signs in for Gmail, Calendar and Drive only. Google Analytics and Google Ads need a Google OAuth app of your own: Settings › Connectors › Google › Use a Google OAuth app of your own…
  • An account that turned Analytics or Ads on with Yardlet's app keeps Gmail, Calendar and Drive as they are. Analytics and Ads show Needs sign-in until you save an app of your own and reconnect the account.

New

  • A task's terminal has tabs. + opens another shell in the task's folder, and a tab's menu renames, restarts or closes it. ⌃` shows and hides the terminal, as ⌘J does, and Run in terminal types only at a shell's prompt.
  • Antigravity CLI 1.4.11 and later runs over ACP, as the other ACP agents do, with its approval requests, Yardlet's tools and each turn's usage.
  • Import conversation… also lists OpenCode, Kimi Code, Grok Build and Hermes Agent conversations.
  • Kimi Code and Grok Build can keep extra accounts, and Settings › Accounts reads Muse Code's and Kimi Code's sign-ins.
  • A scheduled run starts on another account when its own has 10% or less of a limit left.
  • A Claude limit card offers Resume once its limit has reset.
  • Right-click a link in a conversation to open a task in a new tab, a split view or the side panel, a page in the task's browser or your default browser, or a file in Yardlet, its own app or Finder.
  • Personal agents: a dot that writes while you are elsewhere is marked unread and sends a notification, which Settings › Notifications › Personal agent messages turns off. Dot conversations show images and each message's time, a dot's details list the Codex tasks it started, and agents can read your dots.
  • The browser panel's bars, such as an agent's handoff, a permission question and the password manager's offers, sit above the page instead of over it.
  • A task's saved browser tabs load only when shown, as Chrome restores tabs.
  • The password manager offers to save a password sent from a dialog with no form, and the key button lists what the field takes, account first.

Fixes

  • Signing in to a site in one task no longer sets off a chain of cookie copies between tasks that could sign them out of accounts such as Google's.
  • Dragging the shown tab in the title bar moves the tab, not the window.
  • Going back to one of the last four tasks a window showed is quicker, a long turn opens with only the rows in view, and a streaming answer takes work only for the turn it changes.
  • Messages no longer stay in memory after they leave the screen on macOS 27.
  • Retry on an error card sends the retry message again instead of the button's words.
  • A single tilde, as in 240~400 ms, is no longer drawn as strikethrough.
  • The composer grows once when a line wraps, without a flash of the scroller.
  • After a newer agent CLI is installed, scheduled tasks and work a quit cut off start the newer one.
  • A stopped turn's queue no longer stays paused over an empty list.
  • Antigravity sign-in reaches its browser step with the CLI details hidden.

Yardlet 0.11.6

October 31, 2026 · Release on GitHub

Yardlet starts on macOS 15 again. Since 0.11.0 it quit as soon as it opened there. If you are on macOS 15, download this version: the earlier ones cannot open to update themselves.

New

  • The browser panel saves and fills your addresses and payment cards. A card fills only after Touch ID, never with its security code, and never for an agent.
  • Sign-ins that ask for the username first keep it for the password step, and other fields such as an AWS account ID are saved with the item. The save bar closes with an X and says Save when it adds a username.
  • Move a task one level up or under another task in the sidebar, from its menu or by dragging it.
  • Personal agents: read a dot's activity records and reply in threads in Yardlet.
  • Settings says when Yardlet's instructions reach a task: when Yardlet starts or resumes it.

Fixes

  • Your own messages stay in view when a turn's work folds.
  • A Codex error shows once after Retry.
  • A subagent cut off by quitting tells the task that was waiting for it, and quitting to update waits for working subagents too.
  • Moving an account's tasks to another folder carries on after a quit.
  • A task cannot be archived while work it started is still running.
  • An agent CLI that stops reading no longer ends Yardlet, and a shell command is no longer cut short while Yardlet is busy.
  • Less work on the main thread while Codex streams, in tasks with many saved cards, and while subagents run.
  • A saved connector file that cannot be read is left as it is, and Settings says so, instead of being replaced.
  • The password the vault made is kept unless the page certainly did not take it.

Yardlet 0.11.5

October 30, 2026 · Release on GitHub

New

  • The built-in browser plays H.264 video and AAC audio, so MP4 video on sites such as X and LinkedIn plays as it does in Chrome.
  • Find and pick any saved password or code from the browser panel. Settings › Passwords and the key button's list search by name, username or site, and the key button shows on every site while the vault holds an item.
  • Two-factor codes: one-time code fields are found in more languages and sign-in steps. A code saved without a site is linked to its account's sign-in when nothing else could be meant, and the rest are listed in Settings › Passwords with a suggested site.
  • A blank browser tab shows a start page with the pages the task's tabs showed, as Safari, Chrome and the Codex app do, and the side panel's launcher offers them too.
  • Memory saver has Chrome's Moderate, Balanced and Maximum levels. A tab an agent opened that no panel showed is let go ten minutes after the agent's turn.
  • A Codex account's banked usage-limit resets show beside its limits and on its limit card, and one is used only after you confirm.
  • Before removing a saved Claude account, move its tasks to another folder of the same account.
  • A task started from another task nests under it in the sidebar, up to two levels.
  • Dots: send files and photos, see what a dot is working on, and answer its approvals, forms and option questions in Yardlet. Dot avatars animate, and moving between personal agents and tasks is quicker.
  • An agent can quote you by a phrase, and the message that holds it is passed on as you typed it.

Fixes

  • Long conversations and streaming Codex answers take much less work on the main thread, so scrolling and typing stay smooth with long histories, many saved cards and running subagents.
  • A Codex turn that failed on a busy server can be retried.
  • A Codex turn folds its work only once a final answer begins, as the Codex app does.
  • Agents get clearer failures from Yardlet's tools and the browser tools, with whether calling again can help.

Yardlet 0.11.3

October 28, 2026 · Release on GitHub

Security

  • Agent tools are more limited in what they can reach: scheduled tasks an agent writes, which calls may use a task's tools, filled passwords and uploads.
  • Phone pairing and linking are hardened. The first phone protocol is no longer supported, so pair again with the current app.
  • The phone relay limits connections a Mac has not answered.

New

  • Choose the app's language in Settings › General: System, English or 한국어.
  • Keep tasks working with the lid closed, when you turn it on in Settings › General.
  • ⌘K finds tasks as well as commands.
  • Back and Forward (⌘[ and ⌘], or the mouse's back and forward buttons) go through what the window showed. Over a browser page, the mouse buttons go through that page's history.
  • With one tab, ⌃Tab and ⌃⇧Tab go to the next and previous task.
  • A button's tooltip shows its menu bar key.
  • The browser's address field suggests pages and searches as you type.
  • A call's images show on its line, and whole when the line is opened.
  • A two-factor code saved without a site is offered on the site its name names.
  • Agent CLIs installed with nvm, Volta, bun, npm or pnpm are found when Yardlet opens from the Dock.
  • Double-click the sidebar's line to return it to its standard width.

Fixes

  • An agent CLI that exits on its own no longer keeps two CPU cores busy.
  • A streaming Codex answer no longer redraws its whole turn, and scrolling the sidebar to its top no longer redraws the window.
  • Button tooltips show again after a scroll.
  • A task's terminal keeps running when the task leaves the screen.
  • Codex's running turn no longer clears right after you send.
  • A long tool call's progress no longer arrives after its reply.

Thanks to @minsujang0 for the detailed reports behind several of these changes.

Yardlet 0.11.2

October 27, 2026 · Release on GitHub

New

  • Yardlet can be your default browser (System Settings › Desktop & Dock › Default web browser). A link you open in another app opens in a new tab beside the task you are looking at. Passkeys from iCloud Keychain don't work in it yet; security keys and passkeys on your phone (QR code) do.
  • Memory saver (Settings › General): tasks you haven't used in a while let go of their browser tabs and agent processes, and come back when you return to them.

They are new, so please open an issue if one doesn't connect. - Microsoft 365 (Outlook mail and calendar, OneDrive, Teams), with your own Microsoft Entra app for now. - Google Analytics and Google Ads, read only. - Zoom Meetings, Team Chat and Docs, read only, with your own Zoom app. - Twilio Docs: searches Twilio's public documentation.
  • Open a conversation image over the window, fitted, with zoom, the arrow keys and Esc.
  • Click any file in a conversation to open it: files outside the task's folders read-only, images and PDFs shown, folders in Finder.
  • A downloaded update shows Restart to update above the account button and in the menu bar menu.
  • Each agent starts on the newest CLI found on this Mac when you haven't picked one, and settings say when a newer one is elsewhere.

Fixes

  • A browser dialog or file chooser waits in its own tab instead of blocking the window, and shows when you go back to that tab.
  • An agent no longer takes over the tab you are using; it works in a tab of its own.

Yardlet 0.11.0

October 27, 2026 · Release on GitHub

The first public release of Yardlet, a native macOS app for running coding agents. Codex, Claude Code and other agent CLIs open side by side in one window of projects and tasks, while each agent keeps its own agent loop, sign-in and session history.

This repository used to hold Yardlet's command-line predecessor, a Rust CLI. Its code and releases (v0.10.3 and earlier) stay available on the legacy-cli branch and its tags.

Highlights

  • One window for Codex, Claude Code, OpenCode, Cursor Agent, Antigravity CLI, Kimi Code, Grok Build, Pi and others, each started with the CLI and account you already use.
  • Sessions stay in each agent's own store, so a task resumes in the original app or CLI and back.
  • Several accounts per provider, with each account's session and weekly limits.
  • Review the last turn's diff, restore or fork files, follow a pull request's checks through gh, and keep a terminal and files pane beside the conversation.
  • Connectors for every agent: Gmail, Google Calendar and Google Drive through Yardlet's built-in MCP server on your Mac, plus GitHub, Slack and remote MCP services.
  • A built-in Chromium browser the agents can drive while you watch.
  • Scheduled tasks, and session tools that let one task read, message or start another.
  • Updates through Sparkle from this release on.
