Yardlet Changelog

What changed in each version of the Yardlet app. Yardlet updates itself, and GitHub Releases has the downloads. Changes on main that are not released yet are not listed.

Yardlet 0.11.5

October 30, 2026 · Release on GitHub

New

  • The built-in browser plays H.264 video and AAC audio, so MP4 video on sites such as X and LinkedIn plays as it does in Chrome.
  • Find and pick any saved password or code from the browser panel. Settings › Passwords and the key button's list search by name, username or site, and the key button shows on every site while the vault holds an item.
  • Two-factor codes: one-time code fields are found in more languages and sign-in steps. A code saved without a site is linked to its account's sign-in when nothing else could be meant, and the rest are listed in Settings › Passwords with a suggested site.
  • A blank browser tab shows a start page with the pages the task's tabs showed, as Safari, Chrome and the Codex app do, and the side panel's launcher offers them too.
  • Memory saver has Chrome's Moderate, Balanced and Maximum levels. A tab an agent opened that no panel showed is let go ten minutes after the agent's turn.
  • A Codex account's banked usage-limit resets show beside its limits and on its limit card, and one is used only after you confirm.
  • Before removing a saved Claude account, move its tasks to another folder of the same account.
  • A task started from another task nests under it in the sidebar, up to two levels.
  • Dots: send files and photos, see what a dot is working on, and answer its approvals, forms and option questions in Yardlet. Dot avatars animate, and moving between personal agents and tasks is quicker.
  • An agent can quote you by a phrase, and the message that holds it is passed on as you typed it.

Fixes

  • Long conversations and streaming Codex answers take much less work on the main thread, so scrolling and typing stay smooth with long histories, many saved cards and running subagents.
  • A Codex turn that failed on a busy server can be retried.
  • A Codex turn folds its work only once a final answer begins, as the Codex app does.
  • Agents get clearer failures from Yardlet's tools and the browser tools, with whether calling again can help.

Yardlet 0.11.4

October 29, 2026 · Release on GitHub

Security

  • Values the password manager fills are kept away from agents in more places.

New

  • Personal agents, below Scheduled tasks in the sidebar, opens your Dots conversation. Scroll up to read earlier messages, and open its details panel for activity, schedules, computers and attachments.
  • At a new password field, Yardlet suggests a strong password, as Chrome and Safari do. It is saved right away, beside any password the item already has, and agents can make one when they sign up for an account.
  • Gmail drafts and sends can attach files from your Mac, and a draft can be deleted.
  • Forty more remote MCP services in the connector directory.
  • An agent's reply can link to the tasks it mentions.

Fixes

  • A turn's error card shows where the turn ended, and offers Retry only when retrying can help.
  • A folded turn keeps its calls in one summary line, and a Codex reasoning summary folds like Claude Code's thinking.
  • Reconnect signs in again when a server that listed its tools without a sign-in refuses a call.
  • A task's terminal reads a wrapped line as one line, and a program still running in it keeps the task shown as working.

Yardlet 0.11.3

October 28, 2026 · Release on GitHub

Security

  • Agent tools are more limited in what they can reach: scheduled tasks an agent writes, which calls may use a task's tools, filled passwords and uploads.
  • Phone pairing and linking are hardened. The first phone protocol is no longer supported, so pair again with the current app.
  • The phone relay limits connections a Mac has not answered.

New

  • Choose the app's language in Settings › General: System, English or 한국어.
  • Keep tasks working with the lid closed, when you turn it on in Settings › General.
  • ⌘K finds tasks as well as commands.
  • Back and Forward (⌘[ and ⌘], or the mouse's back and forward buttons) go through what the window showed. Over a browser page, the mouse buttons go through that page's history.
  • With one tab, ⌃Tab and ⌃⇧Tab go to the next and previous task.
  • A button's tooltip shows its menu bar key.
  • The browser's address field suggests pages and searches as you type.
  • A call's images show on its line, and whole when the line is opened.
  • A two-factor code saved without a site is offered on the site its name names.
  • Agent CLIs installed with nvm, Volta, bun, npm or pnpm are found when Yardlet opens from the Dock.
  • Double-click the sidebar's line to return it to its standard width.

Fixes

  • An agent CLI that exits on its own no longer keeps two CPU cores busy.
  • A streaming Codex answer no longer redraws its whole turn, and scrolling the sidebar to its top no longer redraws the window.
  • Button tooltips show again after a scroll.
  • A task's terminal keeps running when the task leaves the screen.
  • Codex's running turn no longer clears right after you send.
  • A long tool call's progress no longer arrives after its reply.

Thanks to @minsujang0 for the detailed reports behind several of these changes.

Yardlet 0.11.2

October 27, 2026 · Release on GitHub

New

  • Yardlet can be your default browser (System Settings › Desktop & Dock › Default web browser). A link you open in another app opens in a new tab beside the task you are looking at. Passkeys from iCloud Keychain don't work in it yet; security keys and passkeys on your phone (QR code) do.
  • Memory saver (Settings › General): tasks you haven't used in a while let go of their browser tabs and agent processes, and come back when you return to them.
  • Accounts you already have: add a Claude account folder, share everything but its login with the default folder, take an account off the list, or sign it out and delete it. Yardlet also finds account folders kept in other places.
  • Tasks follow your sign-ins in the built-in browser, a page an agent handed over included, and keep the sign-ins their agents make.
  • Find and connect servers from the MCP registries, Pipedream, Composio and Make, and bring in the MCP servers your other apps already use.
  • More connectors in the directory. They are new, so please open an issue if one doesn't connect. - Microsoft 365 (Outlook mail and calendar, OneDrive, Teams), with your own Microsoft Entra app for now. - Google Analytics and Google Ads, read only. - Zoom Meetings, Team Chat and Docs, read only, with your own Zoom app. - Twilio Docs: searches Twilio's public documentation.
  • Open a conversation image over the window, fitted, with zoom, the arrow keys and Esc.
  • Click any file in a conversation to open it: files outside the task's folders read-only, images and PDFs shown, folders in Finder.
  • A downloaded update shows Restart to update above the account button and in the menu bar menu.
  • Each agent starts on the newest CLI found on this Mac when you haven't picked one, and settings say when a newer one is elsewhere.

Fixes

  • A browser dialog or file chooser waits in its own tab instead of blocking the window, and shows when you go back to that tab.
  • An agent no longer takes over the tab you are using; it works in a tab of its own.

Yardlet 0.11.1

October 27, 2026 · Release on GitHub

Security

  • An agent's browser now asks before opening a file outside the task's folders.

New

  • Apple connectors: Xcode through its own MCP bridge, App Store Connect with your API key, and the Mac's calendars, reminders and contacts.
  • The Google Drive connector reads what is inside Docs, Sheets and Slides, in parts for long files, and edits the ones Yardlet created or copied, asking before each change. It needs no new Google permissions.
  • Mercury in the connector directory, read only.
  • Bring a site's sign-in over from another browser into the built-in one: Chrome, Whale and other Chromium browsers, Comet, Opera GX, Yandex, Helium and Firefox.
  • An agent can hand a browser tab to you for a step only you can take, and wait for you.
  • The built-in browser reads and acts inside frames, those from other sites included, and can emulate a screen size per tab.
  • A child task or subagent can start on the account with the most room before its limits reset.
  • The review shows a Markdown change rendered, and the tasks that read or edited a file.
  • A task shows the servers its processes listen on, and opens one in the task's browser.
  • An agent can start a top-level task or one nested under another open task.

Fixes

  • Fix a crash when a task's side rail showed some tool calls.
  • The composer scrolls its text inside once it passes the field's lines.
  • A streaming conversation keeps following through a swipe toward its end.
  • The browser panel keeps its last frame while it resizes, and its tabs keep their titles while there is room.
  • Chromium's passkey and sign-in windows open over the tab that asked for them.
  • Tabs open past 16 across tasks, and a tab the browser could not open says why.

Yardlet 0.11.0

October 27, 2026 · Release on GitHub

The first public release of Yardlet, a native macOS app for running coding agents. Codex, Claude Code and other agent CLIs open side by side in one window of projects and tasks, while each agent keeps its own agent loop, sign-in and session history.

This repository used to hold Yardlet's command-line predecessor, a Rust CLI. Its code and releases (v0.10.3 and earlier) stay available on the legacy-cli branch and its tags.

Highlights

  • One window for Codex, Claude Code, OpenCode, Cursor Agent, Antigravity CLI, Kimi Code, Grok Build, Pi and others, each started with the CLI and account you already use.
  • Sessions stay in each agent's own store, so a task resumes in the original app or CLI and back.
  • Several accounts per provider, with each account's session and weekly limits.
  • Review the last turn's diff, restore or fork files, follow a pull request's checks through gh, and keep a terminal and files pane beside the conversation.
  • Connectors for every agent: Gmail, Google Calendar and Google Drive through Yardlet's built-in MCP server on your Mac, plus GitHub, Slack and remote MCP services.
  • A built-in Chromium browser the agents can drive while you watch.
  • Scheduled tasks, and session tools that let one task read, message or start another.
  • Updates through Sparkle from this release on.
